# 무상증자 공시 이벤트 스터디

**조회 API만 쓰고 주문은 내지 않는다.** 실계좌 키움 자격증명(`backend/.env`의 `REAL_APPKEY`·`REAL_SECRETKEY`)이 필요하다.
KIND·DART는 키 없이 웹 검색을 쓴다.

## 실행

```bash
cd backend && uv run python ../.claude/skills/bonus-issue-study/study.py            # 올해 1월 1일 ~ 조회일
cd backend && uv run python ../.claude/skills/bonus-issue-study/study.py --from 2026-01-01 --to 2026-10-16
```

옵션:
- `--from` / `--to`: **최초 공시일** 기간(포함). 기본은 올해 1월 1일 ~ 조회일. 사용자가 기간을 말하지 않으면 묻지 말고 기본값으로 돌린다
- `--asof 2026-10-16`: 시세·정정 공시·권리락 안내를 볼 마지막 날(기본: 16시 이후면 오늘, 아니면 어제)
- `--out <dir>`: 출력 폴더(기본 `research/bonus_issue/<from>_<to>/`, git 미추적)
- `--include-paid`: 차트에 유무상증자도 넣기(기본은 순수 무상만. 보고서는 둘 다)
- `--no-charts`: 3분봉 조회·차트 생략
- `--refresh`: 목록·일봉 캐시 무시(공시 본문·지난 분봉 캐시는 유지)

캐시: `backend/backtest_data/bonus_issue/`(git 미추적). Windows 콘솔에서 한글이 깨지면 `PYTHONIOENCODING=utf-8`을 앞에 붙인다.
처음 받는 기간은 종목 수 × (일봉 1회 + 분봉 4일치)라 수 분 걸린다 — 백그라운드로 돌린다.

## 출력

- `report.md`: 데이터 설명, 그룹별 요약 표(순수 무상 / 1주 이상·미만 배정 / 장중·장후 / 코스닥·유가 / 유무상), 종목별 표
- `charts.html`: 왼쪽 목록(전체·장중·장후 필터, ↑↓ 이동) + 일봉 + 3분봉. 차트마다 [변화율 측정](두 점 클릭 → 오른쪽 점의 왼쪽 점 대비 %, 봉의 시·고·저·종가 8px 안이면 그 가격에 붙음, Esc로 지움)
- `events.json`(공시·조건·안내), `analysis.json`(지표 전부 + 그룹 요약)

## 만든 뒤

1. 경고 확인: `조건 못 읽음`(DART 본문 형식이 다름 → `sources.parse_terms` 보강), `반응일 시세 없음`, `분봉 실패`.
2. `charts.html` 확인: 내장 브라우저는 `file://`을 못 열 수 있다. `.claude/launch.json`의 `research-static`
   (research 폴더 정적 서버, 8765)을 `preview_start`로 띄워 `http://localhost:8765/bonus_issue/<폴더>/charts.html`을 연다.
   콘솔 오류, 일봉·3분봉 렌더, 공시·재개 마커를 본다. `launch.json`은 git 미추적이라 없으면 이 항목을 추가한다:
   `{"name": "research-static", "runtimeExecutable": "<repo>/backend/.venv/Scripts/python.exe",
   "runtimeArgs": ["-m", "http.server", "8765", "--bind", "127.0.0.1", "--directory", "research"], "port": 8765}`
3. `SendUserFile`로 `charts.html`(display: render)과 `report.md`를 보낸다.
4. 요약은 `report.md`의 숫자로만: 건수, 장중 공시 매매정지·재개가, 공시~권리락 전, 권리락 후, 신주 상장일, 유무상 대비.
   표본 크기와 같은 기간 지수 흐름(지수 대비 열)을 함께 말한다.

## 정의 (스크립트 동작)

- **대상**: KIND 공시검색 '무상증자' 중 제목에 '결정'이 있고 `[정정]`이 아닌 것 = 최초 공시. 유가(`yu`)·코스닥(`ko`)만.
  기타법인·코넥스·'종속회사의 주요경영사항'은 제외(보고서에 제외 목록). 유무상증자는 `paid_too`로 따로 묶는다.
- **조건**: DART '무상증자' 검색에서 같은 회사의 결정 공시 중 **가장 늦은 접수번호(최종 정정본)** 본문.
  유무상은 'Ⅱ. 무상증자' 이후 구간에서 1주당 배정주식수·신주배정기준일·상장예정일을 읽는다.
- **공시 시각**은 KIND(분 단위). 장전(<09:00)·장중(<15:30)이면 그날이 반응일 D0, 장후·휴장일이면 다음 거래일.
  기준가 B = D0 직전 거래일 종가. N일 = D0를 1일째로 센 종가.
- **권리락일** = 신주배정기준일 직전 거래일. **권리락 안내** = KIND '권리락(무상증자)'(코스닥) 또는
  '권리락 기준가격 안내'(유가 — '무상증자'로는 검색 안 됨, '권리락'으로 따로 검색). 액면병합이 겹치면 '기준가격안내(액면병합 및 권리락)'.
- **매매정지·재개가**: 장중 공시일 1분봉에서 공시 시각 뒤 첫 봉 = 재개. 재개가 = 그 봉 시가.
- 수익률은 수정주가(ka10081 `upd_stkpc_tp=1`). 지수 대비 = KODEX 코스닥150(229200) / KODEX 200(069500).
  세금·수수료·슬리피지 없음.

## 함정

- **KIND**는 빈 검색 필드(`disclosureType01`… 등)까지 전부 보내야 목록을 준다. 아니면 '페이지 오류'.
- **DART** `dsab007/detailSearch.do`는 302로 막힌다 → `detailSearch.ax`. 기본 검색은 최종본만 보여 [기재정정]
  날짜가 공시일처럼 보인다 — `finalReport`를 빼야 원본이 나온다(코드는 KIND 시각을 쓰고 DART는 조건용).
  본문 날짜는 '2026년 05월 27일'과 '2026.05.27' 두 형식이 섞인다.
- **키움 분봉**(ka10080 `base_dt`)은 그 뒤에 생긴 권리락이 반영되지 않은 **원시 가격**이다. 일봉(수정가)과 숫자를
  섞지 말고 같은 날 종가 배율로 환산한다. 9월 이후 분봉에는 NXT(08:00~20:00) 봉이 섞인다(차트는 회색).
- 장중 공시는 유가·코스닥 모두 보통 **40분 정지**(2026년 셀트리온 1건만 정지 없음). 14:40 이후 공시는 정지가
  장 마감을 넘겨 그날 재개가 없다(`당일 재개 없음`).
- 거래량 0인 날이 이어지면 액면병합 등 다른 사유의 거래정지일 수 있다(보고서 끝에 표시).

## 파일

- `study.py`: CLI·순서·report.md·차트 데이터
- `sources.py`: KIND·DART 검색, 본문 파싱, 키움 일봉·분봉(캐시)
- `metrics.py`: 반응일·권리락·상장일 수익률, 매매정지 지표, 그룹 요약
- `template.html`: 차트 페이지. `/*__DATA__*/null`·`/*__META__*/null` 자리를 채운다(lightweight-charts 4.2.0, unpkg)

2026-01~10 첫 조사 결과·해석은 `research/bonus_issue_2026/report.md`.
